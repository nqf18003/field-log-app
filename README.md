# 移動運用ログ (Field Log)

**▶ 使う（公開ページ）: https://nqf18003.github.io/field-log-app/**

山や公園（SOTA・POTA）の移動運用で、スマホの Chrome で交信を記録するウェブページです。インストールは要りません。
IC-705 に Bluetooth でつなぐと、周波数とモードを自動で入れます。記録は ADIF で書き出せます。

> 試作中です（仮の名前）。大事な運用では、念のため紙のログなども使ってください。

## 使えるもの
- Android の Chrome（おすすめ）、パソコンの Chrome・Edge
- IC-705 につなぐには Web Bluetooth に対応したブラウザーが要ります。iPhone・iPad の Safari では無線機にはつなげません（記録だけならできます）。

## できること
- 運用（山頂・公園など）ごとに交信をまとめる。メイン画面は運用の一覧で、押すとその運用の記録の画面になります。
- 交信の記録: 相手のコールサイン・周波数・モード・RST（送った・もらった）。日付と時刻は記録した瞬間の UTC が入ります。
  相手の SOTA・POTA・メモ・グリッドも入れられます。
  周波数は一度入れると、変えるまでそのまま残ります（空でも記録できます）。
  コールサインの形がおかしくても記録し、一覧では赤で表示します（あとで押して直せます）。
- 重複の知らせ: この運用ですでに交信した局なら、コールサインの下に出ます（同じバンド・モードなら赤）。
- IC-705 から周波数とモードを読む（1 秒ごと。本体のダイヤルを回すと入力欄も変わります）。
- ADIF で書き出す（ダウンロード）。Android では「ほかのアプリへ送る」で Google ドライブ・Gmail などへ渡すこともできます（Android の Chrome は .adi のファイルを送らせてくれないので、送るファイルの名前は `….adi.txt` になります。ADIF一括編集ツールはそのまま開けます。ほかのサイトに上げるときは、名前の最後の `.txt` を消してください）。
  ファイル名は `日付-山頂-公園-jcc(jcg)-番号.adi` の形です。
- インターネットにつながらない所でも開けます（下の「オフライン」）。

## 使い方
1. 「新しい運用を始める」を押し、自分のコールサイン・グリッド・山頂（SOTA）・JCC/JCG・公園（POTA）を入れて「保存して記録を始める」。
2. 相手のコールサインなどを入れて「記録する」（キーボードの完了でも記録します）。運用の情報は、記録の画面のいちばん上の欄の「変更」で直せます。
   入力を消すときは、「記録する」の左の「→クリア」のつまみを右の端まですべらせます（押しただけでは消えません）。メモ以外の欄は、全角で打っても自動で半角に直します。
3. 運用が終わったら、下の「メニュー」の「ADIF を書き出す」（または「ほかのアプリへ送る」）。「IC-705 につなぐ」「運用の一覧へ戻る」もメニューにあります。
4. 前の運用は、運用の一覧から押すと開けます（交信を足す・直す・書き出す）。

## IC-705 にはじめてつなぐとき
1. IC-705 の MENU → SET → Bluetooth設定 → Bluetooth を ON にする。
2. 同じ画面の「<<相手の機器からペアリング>>」を押して待ち受けにする。
3. このページの「メニュー」の「IC-705 につなぐ」を押し、「ICOM BT(IC-705)」を選ぶ。
4. 一度つながれば、次からは 2 の手順はいりません。

- スマホやパソコンの「設定」の Bluetooth からはペアリングしないでください（このページが直接つなぎます）。
- 本体の CI-V アドレスは初期値の A4 のままにしてください。
- IC-705 がペアリングを覚えられる Bluetooth LE の機器は 2 台までです（本体の仕様）。3 台目がつながらないときは、
  本体の MENU → SET → Bluetooth設定 → ペアリング/接続 で、使わない機器を削除してからやり直してください。
- 同じスマホで [IC-705 Bluetooth コントローラー](https://nqf18003.github.io/ic705-bt-controller/) を使っているときは、
  本体からは同じ機器に見えるので、ペアリングし直さなくてよい見込みです（まだ確かめていません）。
- 「デモ」ボタンで、無線機が無くても試せます。

## インターネットにつながらない所で使うには（オフライン）
1. インターネットにつながる所で、公開ページを Chrome で開きます。
2. Chrome のメニュー（︙）→「ホーム画面に追加」または「アプリをインストール」を押します（ストアからアプリを入れるわけではありません）。
3. 次からは、ホーム画面のアイコンから開きます。インターネットにつながらなくても開けます。
- インターネットにつながっているときに開くと、新しい版に自動で入れ替わります。

## 記録の保存について
- 記録は、このスマホのブラウザーの中（localStorage）だけに保存します。どこにも送りません。
- ブラウザーのデータを消す・アプリを消すと、記録も消えます。運用のあとは ADIF で書き出してください。
- 書き出していない交信がある運用は、一覧に「書き出していない変更あり」と出ます。
